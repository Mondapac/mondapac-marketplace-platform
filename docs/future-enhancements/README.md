# فهرست متمرکز توسعه‌های آینده
هر قابلیت یا ارتقایی که به آینده موکول می‌شود اینجا و هم‌زمان در مستندات بخش مربوط ثبت می‌شود. این فایل خودکار تولید می‌شود؛ دستی ویرایش نکنید.
قاعدهٔ افزودن: فقط `docs/future-enhancements/items.py` را ویرایش کن (یک ردیف فقط در انتهای فهرست؛ ترتیب شناسه‌ها را بههم نزن)، سپس `python3 docs/future-enhancements/generate.py` را اجرا کن. این کار فهرست اصلی و فایل همهٔ بخش‌ها را هم‌زمان به‌روز می‌کند.
